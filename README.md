# SmartBlock

SmartBlock is an Operating Systems and DBMS project created to make railway maintenance block planning easier.

Different railway departments can submit their maintenance requests, and SmartBlock schedules them while avoiding timing and resource conflicts.

-- Main Features
- FCFS and Priority Scheduling
- Aging to avoid starvation
- Resource Allocation
- Conflict and Deadlock Detection
- Maintenance Block Scheduling
- Simple Control Dashboard

--Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
